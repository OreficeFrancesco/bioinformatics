
# K-mer Analyzer

## Overview

A small Python project for finding occurrences of a k-mer in a DNA sequence.

## Features

- Counts how many times a k-mer occurs in a DNA sequence.
- Identifies the starting index of each occurrence.
- Detects overlapping occurrences.

## Example

**DNA sequence:** `ATATATG`

**K-mer:** `ATA`

### Output

```text
The k-mer ATA appears 2 times.
Its starting indexes are: [0, 2]
```

## Technologies

- Python 3

## Learning Objectives

This project explores string slicing, loops, conditional statements, lists, and basic pattern matching in bioinformatics.
